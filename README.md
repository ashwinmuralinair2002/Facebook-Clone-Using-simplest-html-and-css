# Facebook Login Page Clone

A simple recreation of the Facebook login page using HTML and CSS. This project was built to practise fundamental frontend development concepts and recreate a familiar web interface.

## Features

- Facebook-inspired login page layout
- Email address and password input fields
- Login and create-account buttons
- Language selection section
- Footer with navigation links
- Responsive layout for smaller screens

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries

## Project Structure

```text
Facebook-Clone-Using-simplest-html-and-css/
├── index.html
├── style.css
└── README.md
```

## Running Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/ashwinmuralinair2002/Facebook-Clone-Using-simplest-html-and-css.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

## Note

This project is a static frontend demonstration. The login form does not perform actual authentication or connect to a backend.
